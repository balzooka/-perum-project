# 🏡 Bumipedia — Global & Regional Property Portal

**Bumipedia** adalah platform pencarian, komparasi, dan verifikasi legalitas properti perumahan terintegrasi untuk pasar Indonesia dan internasional.

---

## ✨ Fitur Utama (Key Features)

- 🛡️ **Status Legalitas Terjamin ("Anti-Tipu"):** Transparansi verifikasi dokumen hukum (SHM, PBG/IMB, PBB Pecah per kavling).
- 🌐 **Sistem i18n 17+ Bahasa:**
  - **Bahasa Global:** Indonesia, English, Chinese (中文), Bahasa Melayu, Français, Thai (ไทย), Tagalog (Filipino), Japanese (日本語), Korean (한국어), Russian (Русский).
  - **Bahasa Daerah Indonesia:** Basa Sunda, Basa Jawa, Baso Minang, Hata Batak, Bahasa Papua.
- 🗺️ **Peta Interaktif Leaflet.js:** Mendukung CartoDB Voyager (*Light Mode*) dan Dark Matter (*Dark Mode*) secara adaptif.
- 📊 **Tabel Komparasi Side-by-Side:** Bandingkan hingga 3 unit properti sekaligus (Spesifikasi, Keamanan, Akses Terdekat, dan Legalitas).
- 💰 **Kalkulator Simulasi Pembiayaan:** Dual simulator KPR (Anuitas Bank) & Cash Bertahap (0% Bunga tanpa bank).
- 📱 **Integrasi Langsung WhatsApp & Survey:** Terhubung langsung ke WhatsApp Marketing resmi developer dan formulir jadwal survey lokasi.
- 🎨 **Light & Dark Mode Adaptive:** UI/UX modern dengan Tailwind CSS v4.

---

## 🛠️ Teknologi yang Digunakan (Tech Stack)

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Interactive Map:** Leaflet.js & React-Leaflet
- **State Management:** Zustand
- **Icons:** Lucide React

## 🚀 Panduan Jalankan Secara Lokal (Getting Started)

1. **Clone Repository:**
   ```bash
   git clone https://github.com/USERNAME/perum-project.git
   cd perum-project
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan Development Server:**
   ```bash
   npm run dev
   ```

4. **Buka di Browser:**
   Akses `http://localhost:3000`

## 📦 Deployment ke Vercel

Aplikasi ini dapat di-deploy secara langsung ke [Vercel](https://vercel.com) (100% Free):

1. Push repository ke GitHub Anda.
2. Buka dashboard Vercel -> Klik **"Add New Project"**.
3. Import repository GitHub Anda.
4. Klik **Deploy** (Semua konfigurasi Next.js akan otomatis terdeteksi).
